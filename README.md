# Hotel Booking Analysis Using Power BI

## Project Overview
This project analyzes hotel booking data using Microsoft Power BI. It contains three interactive dashboards to understand booking trends, cancellation patterns, and customer behavior.

## Dashboards

### 1. Booking & Reservation Analysis
- Analyzes total bookings and reservation status.
- Explores booking trends and market segments.
- Examines deposit types and customer lead time.

### 2. Cancellation Analysis
- Analyzes cancelled hotel reservations.
- Compares cancellations across hotel types and market segments.
- Examines monthly cancellation trends and lead time.

### 3. Customer Analysis
- Analyzes customer distribution by country.
- Explores booking channels and monthly booking trends.
- Examines customer types and repeated guests.
